# The Insight Hub

The Insight Hub is a modern blog platform designed to share knowledge, creativity, and perspectives across technology, lifestyle, and innovation. Built with Flask and PostgreSQL, it allows users to register, publish, and engage through insightful posts and comments.

## Features

- User Authentication & Authorization
- Create, Edit & Delete Posts
- Comment System
- Responsive Design
- Admin Dashboard

## Tech Stack

- Python/Flask
- PostgreSQL
- HTML/CSS
- Bootstrap
- JavaScript

## Deployment

### One-click deploy on Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

1. Fork / push this repository to your GitHub account.
2. Go to [Render](https://render.com) and create a free account.
3. Click **New → Blueprint** and connect your repository — Render will read `render.yaml` and automatically provision a **web service** and a **PostgreSQL database**.
4. Set the remaining secrets in the Render dashboard under *Environment*:
   | Variable | Description |
   |---|---|
   | `YOUR_SECRET_KEY` | Auto-generated by Render – change if desired |
   | `Your_SMTP_EMAIL` | Gmail (or other) address used by the contact form |
   | `Your_SMTP_PASSWORD` | App-specific password for the SMTP account |
5. Click **Apply** — your app will be live at `https://<service-name>.onrender.com`.

### Manual local setup

```bash
# 1. Clone the repo
git clone https://github.com/mjeyz/Blog-Website.git
cd Blog-Website

# 2. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure environment variables
cp .env.example .env
# Edit .env with your credentials

# 5. Run the development server
flask run
```

### Continuous deployment (GitHub Actions)

Every push to the `main` branch automatically triggers a new Render deployment via the `deploy.yml` workflow.

To enable this, add your Render Deploy Hook URL as a repository secret:

1. In Render, go to your web service → **Settings → Deploy Hook** → copy the URL.
2. In GitHub, go to **Settings → Secrets and variables → Actions → New repository secret**.
3. Name it `RENDER_DEPLOY_HOOK_URL` and paste the URL.
